# The African Atlas

**Mapping the systems shaping Africa's future.**

The African Atlas is an institution in formation: a long-term container for understanding, connecting, and eventually building across Africa's interconnected systems.

The public website begins with **Maps** — question-led investigations that reveal relationships between food, logistics, capital, health, technology, knowledge, governance, energy, commerce, and human systems.

The larger architecture is intentionally broader than a publication or technology company:

**Knowledge → Intelligence → Ventures → Infrastructure → Institution**

## Why this repository exists

This repository is the first technical container for the African Atlas public experience and future digital infrastructure. It is designed to grow without forcing the idea into a single industry or product category.

## Public positioning

The website deliberately communicates the worldview without exposing the complete venture roadmap. The first public promise is simple:

> One question. One map. One connected continent.

## Current stack

- Static semantic HTML
- Responsive CSS
- Vanilla JavaScript
- Interactive systems graph
- Light / dark theme
- Motion toggle
- Vercel-ready configuration

No framework dependency is required for v0. This keeps the first version durable and easy to deploy. The repository can later evolve to Next.js or another framework once the Atlas needs a CMS, research database, knowledge graph, authentication, or dynamic data products.

## Principle

Technology is an amplifier, not the foundation. The African Atlas should be able to create value through knowledge, relationships, research, ventures, and real-world infrastructure even as specific technologies change.
